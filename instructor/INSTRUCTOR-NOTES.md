# Instructor Notes

## What This Practical Is Testing

This is intentionally a **performance test**, not a recall test.

The student is being asked to operate a professional workflow with substantial scaffolding.

The primary learning target is the loop:

> issue → branch → bounded AI task → review → commit → push → merge → verify

## What Not to Over-Grade

For this first practical, do not make literary quality, prompt-writing ability, or deep subject knowledge the primary grading target.

The content is deliberately scaffolded because the student is learning how to operate the system.

## Suggested Interpretation

A successful student can:

- work in a terminal
- authenticate to GitHub
- clone/open a repository
- create and switch branches
- create GitHub issues
- use an AI assistant against a bounded specification
- inspect changes
- commit and push
- reference issues
- merge work into main
- use GitHub Actions as feedback
- recover enough confidence to repeat the loop

## After-Class Assignment

The next stage should shift from operation toward judgment.

Ask students to personalize the book before the next class.

Possible requirements:

- replace generic examples with examples they care about
- improve weak explanations
- change tone or organization
- add verified museum or institutional references
- identify hallucinations or unsupported claims
- add a deterministic link checker
- ask ChatGPT to review the completed repository
- decide which AI suggestions to accept or reject
- make a final editorial commit

This creates the larger model:

1. deterministic checks for cheap repeatable verification
2. probabilistic AI review for broader pattern recognition
3. human review where judgment matters
