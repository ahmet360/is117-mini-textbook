# Instructions for AI Coding Assistants

You are helping a first-year university student complete a bounded learning exercise.

Follow these rules:

1. Work only on the task in the current issue.
2. Do not redesign the repository.
3. Do not delete existing content unless the issue explicitly requires it.
4. Prefer Markdown over application code.
5. Keep explanations conversational, clear, and appropriate for a first-year college student.
6. Use short sections, concrete examples, tables, diagrams, and comparisons where they improve understanding.
7. When using Mermaid, produce valid Mermaid syntax.
8. Never invent citations, museum objects, books, URLs, quotations, or historical facts.
9. If a factual example cannot be verified, describe the concept without inventing a source.
10. Clearly label suggestions for external research.
11. Keep each issue bounded to its required output file.
12. Before finishing, summarize:
   - files created or changed
   - what was added
   - anything the student should verify

The student, not the AI, is responsible for reviewing and committing the work.
