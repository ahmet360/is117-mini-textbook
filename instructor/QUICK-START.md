# Morning Quick Start

## Create the GitHub repository

1. Create a new empty GitHub repository.
2. On your computer, unzip this project.
3. Open a terminal in the project folder.
4. Run:

```bash
git init
git add .
git commit -m "Initial IS117 practical"
git branch -M main
git remote add origin git@github.com:YOUR-USERNAME/YOUR-REPO.git
git push -u origin main
```

5. In GitHub repository settings, mark the repository as a **Template repository** if you want each student to create their own copy.

## Before Students Start

Confirm:

- GitHub Actions are enabled.
- Students can create repositories from the template.
- Students know their own repository must use SSH for Git operations.
- Students can open the repository with `code .`.
- The five issue prompt files are visible.

## Fast Classroom Flow

Tell students:

> Today you are not being tested on memorizing commands or inventing prompts. You are being tested on whether you can operate the workflow.

Then have them repeat:

**issue → branch → prompt → review → commit → push → merge → check**

five times.
